⚙️  STEP 3: CONFIGURE GATEWAY SERVICE VARIABLES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Click: gateway-service → Variables

Add these variables:
  ENVIRONMENT                    | production
  DEBUG                          | False
  LOG_LEVEL                      | INFO
  SECRET_KEY                     | <generated_32_char_key>
  JWT_ALGORITHM                  | HS256
  JWT_EXPIRATION_HOURS           | 24
  ALLOWLIST_EMAILS               | <your_emails>
  SERVICE_NAME                   | gateway-service
  SERVICE_PORT                   | 8000
  REQUEST_TIMEOUT_SECONDS        | 30
  MARKET_DATA_BASE_URL           | http://market-data-service:8001
  NEWS_SERVICE_BASE_URL          | http://news-service:8002
  ML_SIGNAL_BASE_URL             | http://ml-signal-service:8003

❓ TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Services not running?
  → Check Railway Logs (click service → Logs tab)
  → Look for database connection errors
  → Verify all variables are set

Can't register users?
  → Verify ALLOWLIST_EMAILS is correct
  → Check database initialized (look at gateway startup logs)
  → Test gateway health endpoint

Frontend can't reach API?
  → Check REACT_APP_BACKEND_URL matches gateway domain
  → URL must include https://
  → Verify gateway is running
